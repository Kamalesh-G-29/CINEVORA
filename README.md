# CINEVORA – Movie Comparison & Discovery Platform

CINEVORA is a full‑stack web application that lets users browse, search, compare, and review movies. It features a rich comparison tool with radar, bar, and pie charts, along with a built‑in video player.

## Features
- User authentication (JWT)
- Browse trending, top‑rated, new releases, and popular movies
- Search with autocomplete and voice support
- Detailed movie pages with cast, crew, and user reviews
- Personal watchlist and viewing history
- Compare up to 5 movies across 12 categories (Story, Acting, Visual Effects, etc.)
- Interactive charts (Radar, Bar, Doughnut) and ranked winner list
- 32 color themes
- Video player with multiple server sources

## Tech Stack
**Backend**: Node.js, Express, MongoDB (Mongoose), JWT, TMDB API  
**Frontend**: HTML5, CSS3 (vanilla), JavaScript (Chart.js, FontAwesome)
